# Referência da voz — somente na sua instalação local

Copie para esta pasta os arquivos `referencia.json` e `referencia_usuario.wav`
da pasta `vozes/` do editor que já funciona no seu computador. Isso mantém
a voz aprovada, sem precisar enviar a gravação para o repositório público.

Se você está apenas atualizando os arquivos na instalação existente,
preserve sua pasta `vozes/`: a atualização não precisa apagar nem trocar a gravação.

Esses arquivos locais estão no `.gitignore`. As dependências e modelos da voz
continuam sendo instalados por `instalar_voz_mascote.bat` na pasta do editor.
